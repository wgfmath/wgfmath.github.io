Abstract

Cizma and Linial asked for a classification of metrizable theta graphs. This manuscript solves both their problem and its strict analogue. For a ≤ b ≤ c, the theta graph Θa,b,c is metrizable if and only if a ≤ 2 or (a, b, c) = (3, 3, 3), and it is strictly metrizable if and only if a ≤ 2. Thus Θ3,3,3 is precisely the exceptional theta graph that is metrizable but not strictly metrizable.
