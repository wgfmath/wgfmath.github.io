Abstract

A path system on a graph specifies one path between each pair of vertices and is consistent when every subpath of a specified path is itself specified. This manuscript proves that a finite graph is strictly metrizable if and only if it has no minor isomorphic to any of six graphs: K2,4, the triangular prism, K3,3, two subdivisions of K4, and Θ3,3,3. The result resolves a conjecture of Chudnovsky, Cizma, and Linial.
