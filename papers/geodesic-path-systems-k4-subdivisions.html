Abstract

This manuscript determines the metric realizability of every consistent path system on every subdivision of K4. It gives topological-minor obstructions for ordinary metrizability and classifies the neighborly variant through coordinate obstructions. The positive direction is constructive, using Ferrers relations, monotone potentials, scalar calibration, and finite exact certificates for the remaining core cases.

Keywords
